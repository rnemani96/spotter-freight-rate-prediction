## Pipeline Stages

```
Raw CSV Load
    │
    ▼
Data Cleaning          (nulls → 30,000 lb, market_index median → 1.08; clip rates)
    │
    ▼
Feature Engineering    (59 features: Geo, Distance, Equipment, Weight, Temporal, Market, Lane, Derived)
    │
    ▼
Train / Val Split      (TimeSeriesSplit — trains on past, validates on future)
    │
    ▼
Model CV (10 models)   (LightGBM, CatBoost, XGBoost, HistGB, RF, ExtraTrees, Ridge, Lasso, ElasticNet, MLP)
    │
    ▼
Top-3 Selection        (ranked by CV RMSE)
    │
    ▼
Hyperparameter Tuning  (Optuna — optional, per-model search spaces)
    │
    ▼
Final Training         (full dataset, early stopping for boosters)
    │
    ▼
Ensemble Building      (Nelder-Mead weight optimisation on OOF predictions)
    │
    ▼
Prediction             (validation_predictions.csv + december-chart-inputs.csv)
    │
    ▼
Official Scorer        (score.py.txt — validates both files, generates chart)
```

## Model Comparison (10 models, 5-fold TimeSeriesSplit CV)

| Rank | Model | CV RMSE | CV MAPE | R² |
|------|-------|---------|---------|-----|
| 🥇 1 | **Lasso** | **\$578.36** | 7.02% | 0.851 |
| 🥈 2 | **Ridge** | \$578.97 | 8.35% | 0.851 |
| 🥉 3 | **CatBoost** | \$586.83 | 7.25% | 0.847 |
| 4 | ExtraTrees | \$589.96 | 5.95% | 0.845 |
| 5 | LightGBM | \$599.15 | 8.27% | 0.840 |
| 6 | RandomForest | \$602.46 | 6.46% | 0.839 |
| 7 | HistGradientBoosting | \$612.91 | 7.68% | 0.833 |
| 8 | XGBoost | \$626.71 | 9.86% | 0.826 |
| 9 | ElasticNet | \$741.01 | 26.94% | 0.756 |
| 10 | MLP | \$1086.80 | 48.49% | 0.160 |

**Note**: Lasso/Ridge outperform tree-based models because the feature engineering
pre-computes powerful lane statistics (`lane_rate_mean`, `lane_rate_std`) and market
signals that are highly predictive and linearly separable. The ensemble of the top-3
further reduces variance.

## Quick Start

### Setup (Windows)

```powershell
# One-click setup (creates venv, installs all packages)
.\setup.ps1
```

### Activate Environment

```powershell
.\venv\Scripts\activate
```

### Run Pipeline

```powershell
# Fast predict — top 3 models, no CV (~15 seconds)
python main.py --skip-cv --models lasso ridge catboost

# Full CV across all 10 models, no tuning (~45 minutes)
python main.py --skip-tuning

# Full pipeline with Optuna tuning (hours, best results)
python main.py

# Specific models + limited tuning
python main.py --models lightgbm catboost --n-tuning-trials 30
```

### Manual Scorer Run

```powershell
python score.py.txt `
  --predictions outputs/validation_predictions.csv `
  --december-predictions outputs/december-chart-inputs.csv `
  --output-dir outputs/scorer_results
```

## Design Decisions

1. **OOP architecture**: Every stage is a class (`DataLoader`, `DataCleaner`, `FeatureEngineer`, `Trainer`, `Predictor`, `OutputValidator`). All models inherit from `BaseModel` ABC.
2. **Stateful feature engineering**: `FeatureEngineer.fit()` is called on training data only; `transform()` is applied to all splits — no data leakage.
3. **TimeSeriesSplit CV**: Data is sorted by date. Each fold trains on past, validates on future — simulates real deployment.
4. **10 diverse model families**: Gradient boosting (3 variants), tree ensembles (2), linear models (3), neural network (1) — captures different inductive biases.
5. **Nelder-Mead ensemble**: OOF predictions are used to find optimal blend weights without leaking val labels.
6. **Optuna tuning**: Per-model search spaces with SQLite persistence — studies can be resumed.
